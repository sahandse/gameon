# Gameon

Gameon is a Flutter gaming companion focused on real game data, platform-aware discovery, subscriptions, deals, news, player tracking, and following games.

## Product principles

- No demo or fabricated production data.
- Prefer free/public/official data sources where possible.
- Platform-aware experience: PlayStation, Xbox, PC, Nintendo.
- Minimal, graphical, calm UI with strong visual hierarchy.
- Persian-first RTL experience with correct LTR treatment for game titles, IDs, and brands.
- Offline-friendly caching without presenting stale data as live.

## Initial flow

Theme -> Platform -> Subscription -> Games -> Player IDs -> Favorites -> Personalized Home

## Planned product areas

- Free games
- Paid games
- Deals
- Upcoming releases
- New releases
- PS Plus / Game Pass / Nintendo services based on selected platform
- Following and wishlist
- Full game details
- Persian gaming news from approved sources
- Player stats only where a legitimate API/provider exists

> Status: foundation phase. No release build yet.
